My personal Neovim configuration for Neovim 0.12.4

# Plugins with vim.pack
* mofiqul/vscode.nvim
    - dark vs-code-like theme
* mbbill/undotree
    - Undo tree
* uga-rosa/nvim-colorizer.lua
    - Color highlighting
* linux-cultist/venv-selector.nvim
    - Virtual environment selectors for python
* folke/todo-comments.nvim
    - Highlighted todo comments
* nvim-mini/mini.statusline
    - Better status line
* nvim-mini/mini.icons
    - Icon provider
* nvim-mini/mini.move
    - Move text around with M-hjkl
* nvim-neo-tree/neo-tree.nvim
    - File explorer
* OXY2DEV/markview.nvim
    - Local markdown file rendering
* TJ-Woods/nvim-RunFile
    - Run files with the inbuilt terminal
* TJ-Woods/nvim-StickyNotes
    - per-workspace sticky notes
* mrjones2014/smart-splits.nvim
    - Tmux navigation compatibility
* Aasim-A/scrollEOF.nvim
    - Blank lines on EoF for scrolloff
* SunnyTamang/select-undo.nvim
    - undo selected parts of a file
